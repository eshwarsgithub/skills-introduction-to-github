# GitHub Landing Page

_Build, ship, and collaborate faster with GitHub._

## Welcome to GitHub

GitHub is the platform where developers, teams, and communities build software together. From first commit to production release, GitHub helps you plan work, review code, automate workflows, and secure your software.

## Why teams choose GitHub

- **Collaborate in one place** with pull requests, reviews, and discussions.
- **Automate delivery** using GitHub Actions.
- **Build with confidence** using built-in security and code scanning.
- **Scale with your team** from solo projects to enterprise platforms.

## Get started

1. Create or clone a repository
2. Create a branch for your work
3. Open a pull request to review and merge changes

[Create your first repository](https://github.com/new)
